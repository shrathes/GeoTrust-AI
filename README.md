# 🌍 GeoTrust AI: Spatio-Temporal Trading Address Verification Engine

> **GeoTrust AI** is a zero-latency, client-side web application designed to combat shell companies, virtual office fraud, and phantom business registrations. By fusing spatial zoning data, kinetic foot-traffic pulses modeled on Kaggle urban mobility schemas, and real-time transaction cross-checking, the engine instantly scores trading address authenticity.

---

## 🚀 Key Features

* **Real-Time Signal Fusion Engine:** Dynamically weights declared business industry types against OpenStreetMap (OSM) building zoning layers and pedestrian telemetry.
* **Kaggle-Aligned Mobility Schemas:** Incorporates structured data patterns derived from real-world open pedestrian and retail telemetry datasets (such as Wuerzburg & Dublin pedestrian counts).
* **Zero-Cost GIS Map Integration:** Features an interactive, API-free OpenStreetMap/Leaflet module to visualize exact physical coordinates of verified properties.
* **Interactive 24-Hour Activity Pulse:** Visualizes synchronized kinetic foot-traffic trends versus claimed daily transaction velocity using Chart.js.
* **Preset Scenario Testing:** Instant inspection tools for evaluating Credible, Ghost Address, and Ambiguous Co-Working scenarios.

---

## 🛠️ Technology Stack

* **Frontend Framework:** HTML5, Tailwind CSS (Modern Glassmorphism UI)
* **Mapping & GIS:** Leaflet.js & OpenStreetMap Tiles (API-Free, zero-dependency setup)
* **Data Visualization:** Chart.js
* **Logic & Execution:** Vanilla JavaScript (Client-side execution for instant hackathon offline reliability)

---

## 🏃‍♂️ Running the Project Locally

1. Save your main application code into an `index.html` file.
2. Open the file in any modern web browser (Chrome, Firefox, Edge, Safari).
3. No Node.js installation, backend servers, or external API keys are required—everything executes smoothly client-side!
